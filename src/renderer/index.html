Connect to your scope

  1. Plug the scope into your network with an Ethernet cable.
  2. On the scope press Utility, then IO Setting, then LAN Conf.
  3. Read the IP address shown there (turn on DHCP if it says 0.0.0.0).
  4. Type it in the box at the top and press Connect.

No scope handy? Run make demo to try the app against a simulated one.
